## ✨ Key Features

- 🌌 **High-Tech Dark Mode UI**: A meticulously designed cyberpunk-inspired interface using deep blues and cyan neon accents.
- 🧊 **Glassmorphism Design**: Floating navigation bars and interactive cards with a premium frosted glass effect (`backdrop-blur`).
- 💳 **3D Interactive Lanyard**: A fully interactive 3D WebGL ID Card powered by React Three Fiber & OGL.
- ✨ **Advanced Animations**: 
  - Dynamic **Specular Buttons** that react to mouse movements.
  - Infinite **Marquee/Running Logos** for the tech stack showcase.
  - Theatrical **Splash Screen** with staggered typing effects and smooth slide-up curtain transitions.
  - Built heavily on `framer-motion` for spring physics and layout animations.
- ⚡ **Optimized Performance**: Next.js App Router architecture combined with Turbopack for lightning-fast speeds.

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📱 Project Structure

```bash
├── src/
│   ├── app/            # Next.js App Router (Pages & Layout)
│   ├── components/     # Reusable UI Components (Navbar, Hero, SplashScreen)
│   ├── components/3d/  # WebGL & Canvas Components (LanyardCard)
│   ├── components/animations/ # SpecularButton, CursorGrid, etc.
│   └── public/         # Static Assets & Images
```
